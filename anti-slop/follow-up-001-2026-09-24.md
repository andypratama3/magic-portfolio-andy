## Finding-by-Finding Resolution

### Finding #1 — [HIGH] R-02 (Prohibited Em Dash `—` in UI Prose) — RESOLVED

All em dashes were removed from UI copy and replaced with commas, colons, hyphens, or parentheses while preserving meaning:

- `src/resources/content.js` — every `—` in titles, alt text, roles, and component copy replaced. Line-verified clean after pass.
- `src/components/Mailchimp.tsx` — 3 occurrences replaced (component is exported but not mounted; cleaned for hygiene).
- `src/app/work/projects/*.mdx` — the 10 frontmatter `title:` values replaced. These titles render as page `<h1>`s, card titles, and SEO metadata, so they are UI copy.

**Scoping note (deliberate):** em dashes remain only in the *body prose* of the MDX case studies (long-form project write-ups, e.g. 37 remaining in `productschool.mdx`). The audit scoped R-02 to UI copy locations and did not list MDX body text; per antislop guidance against over-sterilizing and rewriting a user's deliberate editorial style, body prose was intentionally left untouched. Each title that appears in the UI is clean.

### Finding #2 — [MEDIUM] Unified Font — RESOLVED (and upgraded per user directive)

User directive superseded the audit's proposed unification: the site now uses **Geist** (Vercel's font) for UI and **Geist Mono** for code, matching the reference style of vercel.com.

- `src/resources/once-ui.config.js`: `Source_Sans_3` → `Geist`, `IBM_Plex_Mono` → `Geist_Mono` (both from `next/font/google`, weights 300–800, `display: swap`). Geist has no italic axis, so the redundant `style: ["normal", "italic"]` was dropped to satisfy the build.
- `src/resources/custom.css`: fallbacks and header comment updated to Geist. **Fixed a latent circular custom-property bug** at the old line 11 (`--font-code: var(--font-code), ...` was self-referential). Geist Mono now exposes `--font-geist-mono` from next/font and maps to `--font-code`.
- `src/components/Header.module.scss`: mono fallbacks updated in `.linkNum` and `.activeBadge`.
- Verified in compiled CSS: `--font-primary: "Geist"` and `--font-code: var(--font-geist-mono), "Geist Mono", ...`.
