## What is ProductSchool?

ProductSchool is a complete school management system purpose-built for Indonesian K-12 schools. It replaces the scattered collection of spreadsheets, paper records, and manual workflows with **one unified platform** that handles every operational need:

- **Academics** — student records, classrooms, schedules, grades (Kurikulum Merdeka), attendance
- **Finance** — SPP billing, Midtrans digital payments, outstanding tracking, automated reminders
- **Payroll & HR** — employee management, salary components, attendance-based payroll, PDF slips
- **Report Cards** — automated PDF generation with QR verification and digital signatures
- **Parent Communication** — AI-powered WhatsApp assistant that answers bills, grades, and schedules by chat
- **Admissions (PPDB)** — online application, document upload, review → approve → enroll workflow

**Proven in production** at SD Muhammadiyah 3 Samarinda since 2024 — serving 480+ students, 42 classrooms, and 100+ employees on a daily basis.

## Why Schools Choose ProductSchool

### Parents Already Use WhatsApp

The single most impactful feature. Schools don't have to build or advertise a mobile app — parents just chat the school's WhatsApp number:

> "Berapa tagihan anak saya bulan ini?"
> → Bot answers with verified invoice data.

> "Anak saya hadir atau tidak hari ini?"
> → Bot checks attendance records.

> "Kapan jadwal ulangan semester?"
> → Bot reads the academic calendar.

The bot is powered by a local AI model (Ollama) with function-calling against real school data. It verifies parent identity via NISN + phone number, provides only their own children's data, and escalates to human staff when needed. Parents can even photograph payment receipts or sick letters — OCR automatically records the information.

### Automated Report Cards with QR Verification

The rapor system is built around a visual template editor — school staff design report cards using drag-and-drop sections (grades, P5 assessment, inclusion/ABK, signatures) without touching code. The system then:

1. Fills each student's data into the template
2. Renders a print-quality PDF (headless Chrome)
3. Adds a QR verification code and digital signature
4. Batch-generates 480+ rapors with live progress tracking
5. Distributes via WhatsApp, email, or downloadable ZIP

Parents scan the QR code to verify authenticity instantly.

### Digital Payments Built for Middle-Class Schools

SPP billing integrated with **Midtrans** — Indonesia's leading payment gateway:

- Virtual Account (VA) from 20+ banks
- QRIS (Qris) for e-wallet and mobile banking
- Automatic invoice generation each month
- WhatsApp reminders H-3 / H-1 / H+1
- Reconciliation with Midtrans webhooks (every 6 hours)
- Payment matrix view for admin (student × month grid with bulk actions)

## Technical Architecture

**Backend** — Laravel 12 (PHP 8.3), MySQL 8, Redis 7. Service-oriented architecture with 111 service classes, 132 models, and 146 controllers.

**Security** — 18 user roles with 272 granular permissions. Data-level scoping ensures teachers see only their classrooms and parents see only their children. Audit logging, CSRF, HMAC webhook verification, CSP/HSTS headers, rate limiting on all public endpoints.

**Real-Time** — Laravel Reverb WebSocket broadcasts live updates for payments, attendance, grades, schedules, and WhatsApp conversations across the dashboard.

**APIs** — REST API (Laravel Sanctum) with 43 parent endpoints and 9 teacher endpoints for mobile apps. JSON envelope contract with pagination metadata.

**Automation** — 24 console commands + Laravel Scheduler covering bill generation, attendance alpha marking, holiday synchronization, payment reconciliation, and content publishing.

**Testing** — 157+ test files with 1,233 methods (~3,000 assertions), parallelized via Paratest in GitHub Actions CI.
